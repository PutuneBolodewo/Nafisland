**Nafisland v0.1.0 (PulauH)** — first release of the white-label Windows Dynamic Island fork built on the `0.2.30` Oyenza Studio codebase.

### Highlights

- **White-Label Rebrand & Centralized Config (`brand.toml`):** Replaced upstream branding, icons, and mascot assets with Nafisland branding and moved product metadata and external service endpoints into [`brand.toml`](brand.toml). Upstream account/cloud integrations are disabled by default.
- **Horizon & Horizon Pill Themes:** Dynamic 5-phase sky theme (`Morning`, `Day`, `Dusk`, `Night`, `Midnight`) synced to Prayer Times (`Terbit`, `Dzuhur`, `Ashar`, `Maghrib`, `Isya`), featuring multi-stop Direct2D gradients, layered mountain/pine/cabin/lake scenery, a deterministic starfield, and occasional shooting stars that pause when idle, locked, display-off, or on battery saver.
- **EVE Online Intel Tool (Add-on):** Built-in add-on in the **Add-ons (`+`)** tab for live chatlog monitoring with near-zero idle CPU usage:
  - Watches `%USERPROFILE%\Documents\EVE\logs\Chatlogs` using `FindFirstChangeNotificationW` and UTF-16LE shared file reads.
  - Detects active `exefile.exe` multibox clients (`• N active`), tracks each online character's system via `Local_*.txt`, and fails over cleanly between active session logs.
  - Validates solar system names and calculates `0–5` jump distances offline using the compressed New Eden K-space stargate graph (`5,485` systems, `6,991` edges).
  - Supports multi-language filtering, `clr`/`clear` ignore rules, configurable detection radius, cooldown, collapsed island pop-up alerts, and custom alarm sounds (`.wav`, `.mp3`, `.m4a`).
- **Everyday Island Features:** Live media controls and synced lyrics (LRCLIB), Today calendar, Shelf & Phone Drop, Tasks & Focus timer, Prayer times & Caffeine tracker, System monitor, and HUD pop-ups.

### Install

- **Installer:** Download `Nafisland-Setup.exe` (or `Nafisland-Setup-0.1.0.exe`) and run it. Installs per-user under `%LOCALAPPDATA%\Programs\Poni` with no administrator rights required, while keeping settings and data in `%APPDATA%\Poni`.
- **Portable:** Download `Nafisland-0.1.0-portable.zip`, extract it, and run `Poni\poni.exe`.

> Note: The Windows binary is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click **More info → Run anyway** if you trust the build.
