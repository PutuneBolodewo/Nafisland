# Nafisland (PulauH) Brand Files

| File | What |
|---|---|
| `app-icon.svg`, `app-icon-512.png` | Horizon Island app icon: deep twilight-to-horizon sky, rising sun, dark island silhouette, and top living notch with media/equalizer accents |
| `mascot.svg`, `mascot-512.png` | Bull mascot: dark tapered head, curved white horns, floppy ears, half-lidded white eyes, and warm peach snout |

`python tools/make_brand.py` redraws `crates/poni/res/poni.ico`, `docs/brand/app-icon-512.png`, `docs/brand/mascot-512.png`, and `installer/art/*`.
`python server/make_icons.py` redraws the phone drop PWA icons in `server/public/` from `docs/brand/app-icon-512.png`.
